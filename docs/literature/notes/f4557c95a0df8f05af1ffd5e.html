中文标题#

GREM1 通过 LEPR 阳性骨骼细胞介导植入周纤维化

中文摘要#

全球每年约有 130 万例关节植入手术实施，其中约 8 万名患者会发生无菌性松动；而植入周纤维化是导致植入失败的主要原因之一。本研究表明，由瘦素受体阳性骨骼细胞（LEPR+ cells）表达的 BMP 拮抗因子 Gremlin-1（GREM1）是这一过程的关键调控因子。GREM1 在小鼠和人类植入周纤维组织中的 LEPR+ 细胞内均呈高表达。在 LEPR+ 细胞中条件性敲除 Grem1 可减轻植入周纤维化并增强植入周成骨。转录组和功能分析显示，LEPR+ 细胞失去 Grem1 后，BMP 和 WNT 通路被上调，从而增强体内成骨并减少纤维组织形成。作为概念验证，在小鼠中进行关节腔内注射中和性抗 GREM1 抗体可预防并逆转植入周纤维组织，同时促进植入周骨形成。因此，抑制 LEPR+ 细胞中的 GREM1 代表了一种预防和治疗无菌性松动的潜在策略。

背景与研究意义#

关节置换后无菌性松动仍然是翻修手术的核心原因，而其病理基础之一是植入周纤维膜持续形成、骨整合失败和力学固定不足。2024 年同团队已证明 LEPR+ 骨骼细胞是植入周纤维组织的必要且充分来源；本研究进一步向上游机制推进，锁定这些 LEPR+ 细胞中的关键分泌调节因子 GREM1，解释为何同一类骨髓/骨膜来源细胞会偏向纤维化而非成骨命运。

科学问题#

  1. 植入周纤维膜中的 LEPR+ 骨骼细胞究竟通过哪一个关键分子驱动纤维化程序？
  2. GREM1 是否通过抑制成骨相关 BMP/WNT 信号，使 LEPR+ 细胞偏向纤维化命运？
  3. 靶向 GREM1 能否在体内同时实现“抑制纤维化 + 促进骨整合”的治疗效果？

研究思路#

作者沿着“病灶定位 → 遗传删除 → 组学机制 → 治疗验证”的路线展开研究：

  1. 先在人和小鼠植入周纤维组织中确认 GREM1 的细胞来源与表达富集；
  2. 再在 LEPR+ 细胞中条件性敲除 Grem1，观察植入周纤维化与骨形成表型；
  3. 结合转录组和功能分析，判断下游被释放的成骨相关通路；
  4. 最后使用中和性 anti-GREM1 抗体进行概念验证，测试预防与逆转纤维化的可行性。

主要结果#

Result 1 | GREM1 在人和小鼠植入周纤维组织的 LEPR+ 细胞中高表达#

  • 核心发现： GREM1 不是泛组织背景信号，而是植入周纤维病灶中 LEPR+ 骨骼细胞的显著分子特征。
  • 主要证据： 论文摘要明确指出，GREM1 在人和小鼠 peri-implant fibrotic tissue 的 LEPR+ cells 中均高表达。
  • 意义： 为将 GREM1 定位为病理纤维化的上游调控节点提供了细胞来源基础。

Result 2 | 在 LEPR+ 细胞中删除 Grem1 可减轻植入周纤维化并增强骨整合#

  • 核心发现： GREM1 对维持纤维化表型是功能必需的。
  • 主要证据： LEPR+ 细胞特异性条件敲除 Grem1 后，peri-implant fibrosis 减轻、peri-implant osteogenesis 增强。
  • 意义： 说明 LEPR+ 细胞并非固定的纤维化细胞群，而是可被 GREM1 重新编程的骨-纤维分岔点。

Result 3 | Grem1 缺失释放 BMP 与 WNT 通路，推动成骨、抑制纤维化#

  • 核心发现： GREM1 的致纤维化作用与其对 BMP/WNT 成骨程序的抑制密切相关。
  • 主要证据： 转录组与功能分析显示，LEPR+ 细胞失去 Grem1 后 BMP/WNT 通路上调，伴随体内成骨增强和纤维组织减少。
  • 意义： 把“分子—通路—组织命运”三层逻辑串起来，解释植入周纤维化与骨整合失败的机制耦联。

Result 4 | anti-GREM1 可在体内预防并逆转植入周纤维化#

  • 核心发现： GREM1 是可药物化的治疗靶点。
  • 主要证据： 小鼠关节腔内给予中和性 anti-GREM1 抗体后，可同时减少纤维膜并促进植入周骨形成。
  • 意义： 从遗传学因果推进到干预学可行性，具备明确转化价值。

机制总结#

可将本文机制概括为：

LEPR+骨骼细胞 → GREM1高表达 → 抑制BMP/WNT成骨信号 → 促进纤维膜维持/扩张 → 骨整合受阻与无菌性松动

而当 GREM1 被遗传或药理方式抑制后：

GREM1下降 → BMP/WNT释放 → LEPR+细胞向成骨程序偏移 → 纤维化减轻 → 植入周骨形成增强
