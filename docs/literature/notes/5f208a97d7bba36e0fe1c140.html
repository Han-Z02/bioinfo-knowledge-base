英文标题: A single-cell and spatial genomics atlas of human skin fibroblasts reveals shared disease-related fibroblast subtypes across tissues 期刊: Nature Immunology, 2025, Volume 26, pages 1807–1820 通讯作者: Mohammad Lotfollahi, Muzlifah Haniffa (Wellcome Sanger Institute / Cambridge Stem Cell Institute) 数据资源: https://cellatlas.io/studies/skin-fibroblast

一、背景与研究意义#

1.1 疾病背景#

成纤维细胞在塑造组织结构和免疫细胞微环境中起关键作用,是皮肤真皮层的主要间质细胞,负责合成细胞外基质(ECM)蛋白、维持组织结构以及调节伤口愈合过程。

然而,由于以下原因,解析成纤维细胞亚型异质性一直具有挑战性:

  • 缺乏独特的表面标志物
  • 体外培养时倾向于获得活化表型
  • 既往研究未在空间上解析组织微解剖位置
  • 很少有研究同时在皮肤和跨人体组织的多种疾病条件下研究成纤维细胞

1.2 科学问题#

  • 皮肤中成纤维细胞的组成和功能是什么?
  • 它如何在一系列疾病(炎症、癌症和纤维化/瘢痕)中发生变化?
  • 这些群体与其他人体组织的成纤维细胞有什么关系?

1.3 研究意义#

本研究:

  1. 整合已发表的大规模 scRNA-seq 数据集(健康人类皮肤和23种皮肤疾病)
  2. 利用两种不同模态生成空间转录组学数据(10x Visium + 10x Xenium)
  3. 构建高分辨率、空间解析的图谱,包含超过35万个成年人皮肤成纤维细胞
  4. 基于基因表达谱和空间位置提供皮肤成纤维细胞的共识注释
  5. 与其他健康和疾病人体组织中的成纤维细胞数据相关联

2.3 命名框架#

本研究的核心贡献是建立了皮肤成纤维细胞的共识命名法(F1-F8),整合了既往文献中分散的多种描述。

三、健康皮肤的六大亚型(F1-F6)#

3.1 命名与空间位置总览#

亚型 全称 空间位置 关键标志基因 核心功能
F1 Superficial (papillary) 浅层(乳头层) 上皮附近乳头层 COL13A1, COL18A1, COL23A1, APCDD1, WIF1, NKD2 与表皮通过Wnt互作维持身份
F2 Universal (reticular) 普遍(网状层) 网状真皮深层 PI16, CD34, MFAP5(KLF5) 推测为前体细胞;含F_Fascia亚组
F2/3 Perivascular 血管周围 浅层与深层血管周围 PPARG(部分) 与脂肪细胞分化相关
F3 Fibroblastic reticular cell (FRC)-like 浅层血管周围,临近免疫细胞 CCL19, CD74, HLA-DRA, CXCL12, CH25H, IL33, IL15, TNFSF13B, VCAM1 跨组织保守的免疫调节型
F4 Hair follicle-associated 毛囊相关 毛囊周围 ASPN, COL11A1 三个亚簇(DS / TNN+COCH+ / DP_HHIP+)
F5 Schwann-like 施万样 神经结构周围 SCN7A, FMO2, FGFBP2, OLFML2A NGFR+(神经)与RAMP1+(汗腺)

3.2 关键发现#

  1. 整合32个数据集、251位捐献者,鉴定出六种主要成纤维细胞亚型
  2. 通过Visium + Xenium双重空间方法验证亚型存在
  3. 每个亚型占据独特的微解剖生态位
  4. 区域性成纤维细胞支持不同生态位功能

四、疾病适应性和疾病特异性亚型(F6-F8 + 适应性)#

4.1 三大疾病特异性亚型#

亚型 全称 关键标志基因 临床分布
F6 Inflammatory myofibroblasts 炎症性肌成纤维细胞 IL11+ MMP1+ CXCL8+ IL7R+ 早期伤口、瘢痕风险炎症病、癌症中富集;跨组织保守
F7 Myofibroblasts 肌成纤维细胞 ACTA2, COL3A1, POSTN, LRRC15, ADAM12 瘢痕风险 + 已形成纤维化中持续存在;终末分化态
F8 Fascia-like myofibroblasts 筋膜样肌成纤维细胞 F_Fascia相关基因 + ACTA2+COL8A1+SFRP4+ 主要富集于Dupuytren挛缩

4.2 两大疾病适应性亚型#

亚型 基础亚型 特征标志基因 功能意义
F1-like (再生型) F1: superficial CRABP1, CYP26B1, WNT5A 上调与再生相关基因;伤口诱导毛囊新生的来源
F3-like (免疫调节型) F3: FRC-like CXCL9和/或 ADAMDEC1 FRC激活态标志;CXCL9-CXCR3招募T细胞

4.3 PROGENy通路差异#

亚型 显著上调通路
F6 JAK-STAT信号(高)、缺氧信号Hypoxia(高)
F7/F8 TGFβ信号(高)、ECM相关(高),PIEZO2表达(机械转导感受器)

五、主要结果(Result 1-7)#

Result 1: 健康皮肤6亚型的鉴定与空间验证#

核心发现:

  • 基于scVI整合35.7万成纤维细胞,鉴定出F1-F6六亚型
  • 10x Visium + 10x Xenium双重空间验证
  • 每个亚型占据独特微解剖生态位

关键图表:

  • Fig. 1: UMAP + 标志基因Dotplot + 命名框架总结
  • Fig. 2: Visium + Xenium空间定位 + 微环境注释

Result 2: 疾病适应性和疾病特异性亚型#

核心发现:

  • scPoli映射出3个疾病特异性(F6/F7/F8)+ 2个疾病适应性(F1-like、F3-like)亚型
  • F6代表更具炎症性的中间状态(JAK-STAT + 缺氧)
  • F7/F8是终末分化的纤维化状态(TGFβ + ECM)

关键图表:

  • Fig. 3: scPoli嵌入UMAP + 标志基因Dotplot + PROGENy通路评分

Result 3: 成纤维细胞组成特征区分瘢痕风险#

核心发现:

  • 23种皮肤病按瘢痕风险分为三组:低风险 / 中等风险 / 已形成纤维化
  • F6是瘢痕风险组独有,低风险和已形成纤维化组中均不存在
  • F7是已形成纤维化持续存在
  • 随机森林分类器:F6和F7是预测瘢痕风险类别最重要的两个亚型
  • 免疫荧光验证:LRRC15仅在伴瘢痕风险的炎症(化脓性汗腺炎)中表达,不在AD中

关键图表:

  • Fig. 4: 各疾病亚型比例 + LRRC15/ADAM12 IF验证 + Xenium 5k空间验证

Result 4: 肌成纤维细胞的起源#

核心发现:

  • F6是F1 → F7终末肌成纤维细胞分化的中间状态
  • F7可由两条轨迹产生:①F2直接;②F1 → F6 → F7
  • 伤口数据集(58,823细胞)时序验证:Day 0(无) → Day 1(少量F6) → Day 7(F6主导) → Day 30(F7主导)
  • 与小鼠体内谱系追踪一致(Correa-Gallegos 2023 Nature;Driskell 2013 Nature)

关键图表:

  • Fig. 5: 速度伪时间 + 有向PAGA + CellRank2 + 伤口数据集时序

Result 5: 跨组织疾病成纤维细胞群体#

核心发现:

  • ~580万细胞跨组织整合(皮肤、肺、肠、滑膜、心脏、鼻黏膜、子宫内膜)
  • ~100万成纤维细胞进行下游分析
  • F3 FRC-like跨组织保守:在肺(COVID-19、ILD)、肠道(IBD的T区网状细胞)中均发现
  • F6 inflammatory myofibroblasts跨组织保守:在IBD、肺癌、皮肤伤口/瘢痕风险炎症、皮肤癌中均发现
  • 统一了皮肤与跨组织成纤维细胞命名

关键图表:

  • Fig. 6: 既往跨组织研究对应热图 + 跨组织UMAP + Dotplot

Result 6: 跨组织成纤维细胞调节皮肤免疫生态位#

核心发现:

  • F3通过CCL19-CCR7 / CXCL12-CXCR4维持T细胞龛位(CCR7+ MigDCs + CXCR4+ T cells)
  • F6通过多组趋化因子广谱招募免疫细胞:
    • 中性粒细胞:CXCL5/6/8-CXCR2, CSF3-CSF3R
    • 单核/巨噬细胞:CCL5/26-CCR1, CSF3-CSF3R
    • B细胞:CXCL13-CXCR5
  • F6在IBD中与临床炎症评分线性相关(95% CI)
  • F6可作为跨组织疾病活动度生物标志物

关键图表:

  • Fig. 7: 跨组织比例 + 标志基因Dotplot + 龛位识别 + 细胞通讯分析 + IBD线性回归

Result 7: 成年F3 FRC-like的发育起源#

核心发现:

  • 成年皮肤F3 FRC-like可能起源于产前CCL19+ LTo(淋巴组织组织者)样细胞
  • 产前皮肤CCL19+细胞与产前肠道mLTo细胞共聚类
  • F3在人类皮肤中独特富集(小鼠皮肤中相对罕见)——解释了为何人类皮肤具有更复杂的血管周围免疫龛位
  • LTo程序在化脓性汗腺炎中显著激活(CXCL13, FDCSP)→ 与该病中TLS形成相关
  • CXCL9/ADAMDEC1+ F3-like代表活化的FRC状态,通过CXCL9-CXCR3招募T细胞

关键图表:

  • Fig. 8: 产前+成年皮肤整合 + 产前皮肤+肠道整合 + 物种对比

六、机制模型: F3 与 F6 的免疫调节功能对比#

F3: FRC-like (跨组织保守)
├── CCL19 → CCR7 → 迁移性树突状细胞
├── CXCL12 → CXCR4 → T细胞亚群
├── IL33/IL15/TNFSF13B/VCAM1 → 维持免疫细胞存活
└── CD74 + MHC-II → 抗原呈递
功能:维持浅层血管周围免疫龛位(T细胞-DC互作)

F6: Inflammatory Myofibroblasts (跨组织保守)
├── CXCL5/6/8 → CXCR2 → 中性粒细胞
├── CSF3 → CSF3R → 中性粒细胞
├── CCL5/26 → CCR1 → 单核/巨噬细胞
├── CXCL13 → CXCR5 → B细胞
└── MMP1/MMP3 → 组织重塑以促进免疫细胞浸润
功能:广谱招募免疫细胞跨组织

中间分化轨迹(F1 → F6 → F7)是瘢痕形成核心路径

七、与课题方向的相关性分析#

7.1 对瘢痕疙瘩/硬皮病研究的启示#

  1. F6 → F7轨迹可作为治疗靶点:如果在瘢痕疙瘩或硬皮病中阻断F6 → F7转化,可能预防瘢痕形成
  2. F1 → F6 → F7是核心瘢痕形成路径:F1浅层成纤维细胞是F6的前体 → 浅层成纤维细胞活化可能是关键早期事件
  3. HS(化脓性汗腺炎)是高瘢痕风险模型:F6签名最高,可作为研究瘢痕疙瘩前期状态的参考模型
  4. Wnt通路在F1/F2中起关键作用:APCDD1、WIF1、NKD2等Wnt抑制剂 → 调控表皮-真皮互作 → 影响瘢痕形成

7.2 与课题组现有课题方向的对接#

课题方向 可借鉴方法/内容
HS找靶点通路+皮肤单细胞marker F6趋化因子网络(JAK-STAT、缺氧)和免疫招募机制是核心
PMT周细胞+FB 本研究已将周细胞和施万样F5区分;周细胞与F2/3的关系值得深入
瘢痕共病-多组学-MR-GWAS F6/F7的核心基因(IL11, CXCL8, MMP1, POSTN, LRRC15, ADAM12)是潜在GWAS富集基因
皮肤cGVHD HIF1a-PI3Kd-IL13轴 F6中缺氧信号显著上调 → HIF通路与F6功能可能直接关联
皮肤纤维化MD模拟 F1 → F6 → F7轨迹可作为MD模拟的分化路径
CAR-TREM2巨噬细胞治疗瘢痕 F6招募单核/巨噬细胞机制可能与TREM2+巨噬细胞表型相关

7.3 核心可借鉴资源#

  1. 数据资源:https://cellatlas.io/studies/skin-fibroblast(交互式数据探索)
  2. 共识命名法:F1-F8框架可直接应用于自己的研究
  3. 关键标志基因清单:
    • F3:CCL19/CD74/HLA-DRA/IL33/IL15/TNFSF13B/VCAM1
    • F6:IL11/MMP1/CXCL8/IL7R/CXCL5/CXCL13
    • F7:LRRC15/ADAM12/POSTN/COL3A1/ACTA2

八、讨论与结论#

8.1 核心发现#

  1. 共识命名框架:首次定义皮肤成纤维细胞的F1-F8分类,统一既往分散描述
  2. 跨疾病 × 跨组织整合:23种皮肤病 + 14种跨组织疾病,~580万细胞
  3. 空间分辨验证:Visium + Xenium双重验证
  4. 轨迹分析确定起源:F1 → F6 → F7是瘢痕形成核心路径
  5. 发育起源追溯:成年F3可能源自产前LTo样细胞
  6. 临床转化价值:F6与IBD临床评分线性相关,可作为跨组织生物标志物
  7. 物种差异揭示:F3在人类皮肤独特富集,解释人类皮肤复杂免疫结构

8.2 研究亮点#

  • 数据规模前所未有(35.7万成纤维细胞,>210万原始细胞)
  • 多模态整合(scRNA-seq + 空间转录组学 + 跨组织)
  • 命名学共识贡献
  • 临床-基础紧密联系(瘢痕风险分层、IBD生物标志物)

8.3 研究局限性(基于原文推断)#

  • 部分空间数据样本量较小(Visium: n=1 皮损型AD + n=2 非皮损型AD)
