摘要LLM 归库摘要

  • 核心内容： 论文校样（Proof）阶段参考文献体系整理的标准流程，聚焦 EndNote：重复文献处理、Traveling Library 归位、批量补 DOI、DOI 反向验证与脏数据检查。
  • 适用场景： 多人合作写稿后进入校样阶段，参考文献出现重复/缺 DOI/Traveling Library 混入等历史遗留问题。
  • 输入： Word 文稿 + EndNote Library（.enlx 备份）；正文引用关系需先清理干净，再谈补 DOI。
  • 输出： 干净统一的参考文献体系——无重复、无 Traveling Library、编号连续、字段完整、DOI 指向正确、无 DOI 的老文献保持为空。
  • 关键步骤： ①备份（Word 复制 + Compressed Library）；②去重（选主记录→Remove Citation→重插→Update）；③Traveling Library 归位（Export Traveling Library 或 Remove 后重插）；④补 DOI（Find Reference Updates→Update Empty Fields；量大可用 AI 读 Crossref）；⑤DOI 反向验证（拿 DOI 查 Crossref 再比对标题）；⑥脏数据检查（Author/Title/Journal/Year/Volume/Issue/Pages/DOI）；⑦EndNote 重新生成 Reference List。
  • 常见错误： 直接删文末 Reference List 条目（会被 EndNote 重新生成）；Update All Fields 覆盖已正确的作者/期刊格式；自动匹配到同名错误 DOI；为老文献硬找一个相似 DOI（错误 DOI 比没有更麻烦）。
  • 与口腔生信连接： 投稿/返修阶段处理含大量引用的手稿（如综述、机制类文章）时，可用该流程避免参考文献被退修；EndNote 与 Zotero 之间的迁移思路可类比。
  • 下一步处理： 暂未试用；建议下次手稿进入校样阶段时按本页清单核对。
  • 归库说明： 分类到 02 文献精读与汇报库（methods 方法知识），置信度 0.75，理由：EndNote 参考文献整理属论文写作/文献管理方法，非单篇论文，AI 仅为辅助工具。

背景

论文进入校样（Proof）阶段，很多人第一反应是检查错别字和格式，但参考文献往往是最麻烦的部分。尤其经过多人修改后，容易出现：

  • 同一篇文献被引用两次（EndNote 里两条不同记录）
  • 大量文献没有 DOI
  • 合作者插入的引用显示为 Traveling Library
  • 作者、期刊、卷期页字段本身有误

本文整理自一篇实操经验：用 Word + EndNote + AI 科研工作台（Wisp Science）在几天内把 ~90 条参考文献体系重新整理干净。

标准处理流程（固定顺序）

第 0 步：先别急着补 DOI#

DOI 只是表面问题。第一步先确认 Word 里的引用关系是否干净。本次主要发现三类问题：

  1. 参考文献重复——同一篇文献在文末出现两次、对应不同编号。这是正文不同位置引用了 EndNote 里的两条不同记录，不能直接删文末其中一条，否则下次 EndNote 更新还会重新生成。
  2. 大量记录缺 DOI——有作者/题目/期刊/年份但 DOI 字段为空。几篇可人工查，几十篇逐条查询很低效。
  3. 多人协作产生 Traveling Library——EndNote → Edit & Manage Citation(s) 里部分文献显示自己的 Library，部分显示 Traveling Library。说明这些引用是合作者从他自己的库插入的，Record Number 已与你电脑上的库对不上。

第 1 步：动手之前先备份#

校样阶段最怕一顿操作后引用编号乱掉。先做两份备份：

  • Word 文稿：直接复制一份。
  • EndNote：File → Compressed Library 导出一个 .enlx 完整备份。

后面无论删除并重新插入 Citation，还是导出 Traveling Library，出问题都有回退空间。

第 2 步：重复文献不要直接删文末列表#

正确做法：

  1. 确定 EndNote 里哪条记录作为主记录（优先保留信息更完整、有 DOI、有附件、被更多位置引用的那条）。
  2. 回到正文，找到引用另一条 Record 的位置。
  3. 在 Word 中 EndNote → Edit & Manage Citation(s)，选中需替换的引用 → Remove Citation。
  4. 引用编号暂时消失是正常的。保持光标在原位置，用 Insert Citation 重新插入主记录。
  5. 执行 Update Citations and Bibliography。

EndNote 会自动合并重复文献并重排编号。

第 3 步：Traveling Library 怎么处理#

Traveling Library 本身不是错误（EndNote 为协作把引用信息嵌入 Word），但最终校样阶段最好统一回自己的本地库。

分两种情况：

  • 自己的库没有这篇文章：EndNote → Export to EndNote → Export Traveling Library，选择当前使用的库，Word 携带的文献进入本地库。
  • 自己的库已有这篇文章：不建议再次导入（易制造重复）。直接把正文里 Traveling Library 引用 Remove 掉，再从自己的库重新 Insert Citation 即可。例如合作者库里 Gong 2020 是 Record #2，你库里是 #113，就移除后重插。

处理完成后打开 Edit & Manage Citation(s) 从头检查：Library 一栏不应再出现 Traveling Library。

第 4 步：再批量补 DOI#

重复文献和 Traveling Library 处理完后再补 DOI：

  • 只缺几篇：References → Find Reference Updates，优先选 Update Empty Fields（只填空字段）。Update All Fields 可能把已正确的作者、期刊缩写、页码格式覆盖掉。
  • 一次缺几十篇：可让 AI（如 Wisp Science）读取参考文献列表，通过 Crossref 批量查询 DOI，再与 EndNote 记录对应。顺带能发现期刊名缺失、作者字段污染、卷期页不完整等记录本身的问题。

第 5 步：DOI 找到了，也不一定是对的#

自动检索找到的 DOI 格式正常、能打开，不代表就是正确的那篇。案例：标题只有一个词 Osteosarcoma，自动检索找到的 DOI 其实是同名的其他条目，不是引用的 Nature Reviews Disease Primers 综述。

批量补 DOI 不能只判断字段是否非空。标题短、标题通用、同名文章多的文献，自动匹配容易撞车。

第 6 步：最后一定要反向验证 DOI#

人工可随机打开一些 DOI 核对标题/一作/期刊/年份；文献多则做反向验证：拿 DOI 去 Crossref 查询，再把返回的论文标题与参考文献里的标题重新比较。

只有"标题查 DOI"和"DOI 反查论文"两边都能对应上，才算通过。这一步能发现前面的错误 DOI。

第 7 步：没有 DOI 不一定是错误#

部分较早的老期刊文章本身没有注册 DOI。保持 DOI 为空是正确的，不要为了 100% 覆盖率硬找一个相似的 DOI。错误 DOI 比没有 DOI 更麻烦。

第 8 步：顺手检查 EndNote 脏数据#

补 DOI 过程中常发现历史导入的异常记录，如作者名显示成 Meek, D.W.J.D.r.、文章只有年份卷期页但期刊名缺失。说明早期导入时字段解析出错。

校样阶段顺带检查这些字段：Author、Title、Journal、Year、Volume、Issue、Pages、DOI。特别是作者字段出现奇怪缩写、期刊名为空、格式突然与前后不一致的记录。

第 9 步：最终不要手改 Reference List#

所有数据修好后，再回 Word 执行 Update Citations and Bibliography，让 EndNote 重新生成整个参考文献列表。不要直接在文末手工删文献、改作者、填 DOI、改编号——下次 EndNote 更新会被覆盖。

真正该修的是 EndNote Library，不是 Word 里显示出来的 Reference List。

校样稿参考文献检查清单

最终至少确认几件事：

  • 没有 Traveling Library
  • 没有重复参考文献
  • 编号连续
  • 作者、期刊、年份、卷期页完整
  • 应该有 DOI 的文献都有 DOI
  • DOI 确实指向正确论文
  • 确认没有 DOI 的老文献保持为空

AI 辅助经验（Wisp Science）

这类高度结构化、需要大量检索和交叉核对的工作特别适合交给科研 Agent。Wisp Science（本地智能科研工作台）在此案例中做的事：

  • 读取 Word 文稿
  • 理解 EndNote Library
  • 识别异常记录
  • 批量检索 Crossref DOI
  • 对结果做交叉验证（标题查 DOI + DOI 反查论文）

作为人类，需要在关键节点对 AI 做出更清晰的指令。可以依赖 AI 规划解决问题的路径，但是否真的达到目的，仍需自己留心检查。

与口腔生信/写作流程的连接

  • 综述类稿件、机制类文章引用量大，返修阶段可用本流程避免"参考文献退修"。
  • EndNote 与 Zotero 的迁移、去重逻辑可类比（Zotero 同理建议在源库修正而非手改 Word）。
  • 配合本库文献笔记的 DOI/PMID 字段，可在整理时统一核对。
