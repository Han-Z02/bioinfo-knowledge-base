标题#

Peritumoural adipose tissue promotes ferroptosis resistance by 3-hydroxykynurenine-mediated suppression of ferritinophagy

  • 期刊：Nature Cell Biology（NCB）
  • 发表日期：2026年3月11日
  • DOI：10.1038/s41556-026-01907-x
  • 通讯作者：Huai-Qiang Ju（aju-HQ）、Rui-Hua Xu
  • 第一作者：Yan-Yu Zhang、Yi Han、Yue-Tao Tan
  • 机构：中山大学肿瘤防治中心、华南肿瘤学国家重点实验室
  • Zotero ItemID：1868

一、研究背景与科学问题#

1.1 临床背景#

肿瘤周围脂肪组织（Peritumoural Adipose Tissue，PAT）是多种腹部恶性肿瘤（结直肠癌CRC、胃癌GC、卵巢癌等）的邻近组织成分，与肿瘤直接接触。临床研究显示，PAT 与多种癌症的不良预后密切相关，是CRC无复发生存期的独立预测因子。然而，PAT 驱动肿瘤进展和治疗耐药的具体分子机制尚不完全清楚。

1.2 铁死亡概述#

铁死亡（Ferroptosis）是一种由铁依赖性脂质过氧化驱动的调控性细胞死亡形式。细胞内游离铁（Fe²⁺）水平是铁死亡敏感性的关键决定因素：

  • 铁蛋白（Ferritin）：由FTH1（重链）和FTL（轻链）组成，通过螯合 Fe²⁺ 维持细胞铁稳态
  • 铁蛋白自噬（Ferritinophagy）：NCOA4识别并结合铁蛋白，将其递送至溶酶体降解，从而释放储存的铁，促进脂质过氧化和铁死亡
  • GPX4：谷胱甘肽过氧化物酶4，是铁死亡的核心抑制因子

1.3 已有研究基础#

先前研究已表明：

  • 铁死亡是一种具有免疫原性的细胞死亡形式，CD8⁺ T细胞来源的IFN-γ可在免疫检查点阻断治疗（ICB）期间增强肿瘤对铁死亡的敏感性
  • 肿瘤微环境中的IL-1β可通过维持铁稳态保护肿瘤细胞免受铁死亡
  • 脂肪细胞可保护三阴性乳腺癌细胞免受铁死亡，但具体机制未明

1.4 关键科学问题#

  1. PAT是否调控肿瘤细胞的铁死亡敏感性？
  2. PAT通过何种分子机制赋予肿瘤细胞铁死亡抵抗？
  3. 靶向PAT驱动的铁死亡抵抗能否增强免疫治疗疗效？

二、整体研究思路#

本研究采用"临床发现 → 体外验证 → 机制解析 → 动物模型 → 治疗转化"的递进式研究策略：

临床问题（PAT与不良预后）
    ↓
建立肿瘤模型（皮下 vs iWAT脂肪组织部位）
    ↓
代谢组学筛选 → 锁定KYN通路
    ↓
代谢物功能验证 → 鉴定3-HK为核心分子
    ↓
分子机制解析 → NCOA4-铁蛋白自噬抑制
    ↓
药理学干预 → IDO1/TDO2抑制 + 抗PD-1联合治疗
    ↓
临床样本验证

技术路线亮点#

技术 应用

三、逐个 Result 总结#

Result 1：PAT赋予肿瘤细胞铁死亡抵抗力，并降低免疫疗法疗效#

【目的】 建立模型验证PAT是否影响肿瘤细胞对铁死亡的敏感性，并探究其对免疫治疗的影响。

【主要证据】

  1. 模型构建：

    • 将CRC肿瘤分别植入小鼠背部皮下（非脂肪组织部位）或腹股沟白色脂肪组织（iWAT，脂肪组织相关部位）
    • 使用GPX4-iKD（强力霉素诱导性敲低）和SLC7A11-iKD系统调控铁死亡

  2. 铁死亡敏感性差异：

    • iWAT植入的DLD1异种移植瘤比皮下肿瘤更耐受铁死亡（GPX4敲低后）
    • IHC证实：iWAT肿瘤中脂质过氧化标志物（4-HNE、MDA）水平显著降低
    • MC38肿瘤中SLC7A11诱导性敲低也观察到了类似的耐药性

  3. 药理学验证：

    • iWAT植入的MC38肿瘤对铁死亡诱导剂IKE的敏感性显著降低
    • 肿瘤生长抑制率从皮下植入的82.5%下降到PAT相关肿瘤的0.24%
    • Lip-1可逆转IKE效应（证实为铁死亡依赖性）

  4. 免疫依赖性：

    • PAT仅在免疫功能正常的小鼠中促进肿瘤生长，在免疫缺陷裸鼠中无此作用
    • CD8⁺ T细胞耗竭后，促肿瘤作用消失
    • Rag1⁻/⁻小鼠过继转移CD8⁺ T细胞后，非脂肪组织部位肿瘤被选择性抑制

  5. 免疫治疗影响：

    • iWAT植入的CRC肿瘤对抗PD-1治疗的反应显著降低
    • III-IV期肿瘤（脂肪组织嵌入状态）的脂质过氧化信号显著弱于I期肿瘤

【核心发现】

PAT通过保护肿瘤细胞免受铁死亡应激来促进肿瘤生长，且这种保护作用依赖于CD8⁺ T细胞介导的免疫监视。PAT还降低了免疫检查点阻断治疗（ICB）的疗效。

Result 2：PAT通过铁蛋白介导的铁螯合赋予肿瘤细胞铁死亡抵抗#

【目的】 阐明PAT分泌何种因子来介导铁死亡抵抗，并鉴定其下游靶标。

【主要证据】

  1. 体外模型建立：

    • 建立脂肪来源条件培养基（adipose-CM）检测系统
    • adipose-CM显著减弱RSL-3诱导的人CRC细胞（DLD1、HCT116）和小鼠MC38细胞中的脂质过氧化和铁死亡

  2. 抗氧化剂非依赖性：

    • 维生素E和辅酶Q10（CoQ10）等抗氧化剂水平在脂肪相关肿瘤中并未改变
    • 排除已报道的RTA（自由基捕获抗氧化剂）机制

  3. 蛋白质组学筛选：

    • DIA-MS分析：脂肪-CM处理的MC38细胞表现出独特的蛋白质组学特征
    • 关键发现：FTH1和FTL（铁蛋白亚基）显著上调，而其他核心铁死亡调节因子保持不变
    • 免疫印迹验证：FTH1/FTL的选择性诱导

  4. GSH非依赖性机制：

    • adipose-CM处理的细胞内GSH水平未改变
    • 表明这是一种以铁蛋白上调为中心的GSH非依赖性机制

  5. Fe²⁺水平降低：

    • FerroOrange染色：脂肪-CM处理的细胞内Fe²⁺水平降低
    • 提示铁蛋白增加并非由于铁积累，而是主动螯合铁

  6. 功能验证：

    • FTH1/FTL双重敲低：
      • 消除adipose-CM对Fe²⁺的消耗
      • 消除adipose-CM对RSL-3诱导铁死亡的保护作用
    • 结论：铁蛋白对脂肪-CM介导的细胞保护作用至关重要

  7. 体内验证：

    • 来自iWAT部位的MC38肿瘤细胞表现出更高FTH1/FTL表达、更低细胞内Fe²⁺和脂质过氧化水平
    • 腹膜肿瘤（脂肪丰富微环境）的FTH1/FTL表达也高于皮下肿瘤
    • FTH1/FTL基因敲低抑制腹膜肿瘤进展

【核心发现】

PAT通过分泌某种因子，上调肿瘤细胞中的铁蛋白（FTH1/FTL）水平，螯合细胞内铁，从而赋予铁死亡抵抗力。这是一种完全独立于GSH系统的新机制。

Result 3：PAT建立富含犬尿氨酸（KYN）的肿瘤微环境，上调铁蛋白#

【目的】 鉴定脂肪-CM中赋予铁死亡抵抗性的具体活性因子。

【主要证据】

  1. 活性因子性质：

    • 活性具有热稳定性，且在3 kDa滤膜过滤后仍然存在
    • 表明低分子量代谢物是活性因子

  2. 代谢组学筛选：

    • LC-MS/MS分析：脂肪-CM和iWAT移植MC38肿瘤中，犬尿氨酸（KYN）是唯一持续升高的代谢物
    • CRC患者和荷MC38肿瘤小鼠的PAT条件培养基中KYN浓度：分别为124 μM和97 μM

  3. KYN功能验证：

    • KYN剂量依赖性增加FTH1/FTL表达
    • KYN降低细胞内Fe²⁺水平
    • KYN抑制RSL-3诱导的脂质过氧化和铁死亡

  4. KYN代谢通路：

    • KYN是色氨酸（TRP）经IDO1/TDO2代谢的产物
    • CRC肿瘤中IDO1/TDO2表达上调 → KYN积累
    • snRNA-seq：Ido1在脂肪细胞中高表达，Tdo2在脂肪前体细胞（pACs）和脂肪来源干细胞（ASCs）中高表达
    • 脂肪细胞、pACs和ASCs共占PAT细胞总量的54.8%

  5. PAT特异性：

    • PAT及其条件培养基中的KYN水平显著高于对侧iWAT（正常白色脂肪组织）
    • 证实肿瘤邻近微环境中KYN产生的特异性增强

【核心发现】

PAT通过上调IDO1/TDO2表达，建立富含KYN的肿瘤微环境。KYN被癌细胞摄取后，上调铁蛋白水平，螯合细胞内铁，赋予铁死亡抵抗力。

Result 4：KYN衍生的3-HK是PAT介导的铁死亡抵抗的关键代谢物#

【目的】 确定KYN的哪种下游代谢物是驱动铁蛋白积累和铁死亡抵抗的关键分子。

【主要证据】

  1. 代谢物筛选：

    • 系统检测TRP-KYN通路中间体对铁死亡敏感性的影响
    • KYN、3-HK和3-HAA均能赋予癌细胞铁死亡抵抗力
    • 3-HK和3-HAA是两个酶促步骤的连续产物

  2. 基因操作验证：

    • 敲低KMO（KYN→3-HK的限速酶）：
      • 降低FTH1/FTL比值
      • 增加Fe²⁺水平
      • 增强脂质过氧化
      • 使细胞对铁死亡更敏感
    • 敲低KYNU（KYN→3-HAA的酶）：
      • 增强KYN的作用
      • 进一步提高FTH1/FTL比值
      • 进一步降低Fe²⁺和脂质过氧化水平
      • 保护细胞免于铁死亡

  3. 3-HK直接功能：

    • 持续补充3-HK剂量依赖性：
      • 上调FTH1/FTL表达
      • 降低活性铁水平
      • 抑制脂质过氧化
      • 增强铁死亡抵抗力

  4. 机制解析（翻译后调控）：

    • 3-HK不影响FTH1/FTL mRNA表达
    • 脉冲追踪实验：3-HK延缓FTH1的降解
    • 提示：3-HK通过抑制铁蛋白降解（而非促进合成）来稳定铁蛋白

  5. NCOA4依赖性：

    • 3-HK降低溶酶体Fe²⁺含量
    • 在NCOA4敲除（KO）细胞中：3-HK和KYN均无法上调铁蛋白或降低Fe²⁺
    • NCOA4 KO细胞中，3-HK对RSL-3的保护作用显著减弱
    • 证实：3-HK的作用完全依赖于NCOA4

  6. 通路特异性排除：

    • AHR KO不影响3-HK介导的FTH1/FTL上调（排除AHR通路）
    • NRF2/SLC7A11 KO中，3-HK仍能诱导FTH1/FTL（排除NRF2通路）
    • CD44 KO中，3-HK仍能上调FTH1（排除铁摄取CD44通路）

【核心发现】

3-HK是驱动铁蛋白积累的关键代谢物。3-HK通过NCOA4依赖的方式抑制铁蛋白自噬，稳定铁蛋白，从而螯合铁并赋予铁死亡抵抗——这一过程完全独立于经典的抗氧化通路（NRF2/AHR/CD44）。

Result 5：3-HK直接结合NCOA4并阻断铁蛋白自噬的启动#

【目的】 在分子层面阐明3-HK如何抑制NCOA4介导的铁蛋白自噬。

【主要证据】

  1. FTH1-NCOA4相互作用受损：

    • 免疫荧光：3-HK或KYN处理显著降低FTH1和NCOA4的共定位
    • Co-IP：3-HK减弱FTH1和NCOA4之间的直接结合

  2. 代谢酶调控验证：

    • KYNU敲低：降低FTH1-NCOA4结合
    • KMO敲低：增强FTH1-NCOA4结合
    • 与功能实验结果完全一致

  3. 体外结合实验：

    • 纯化了全长NCOA4（NCOA4-fl）和铁蛋白结合域（NCOA4³⁸³⁻⁵²²）
    • 3-HK特异性抑制FTH1与NCOA4的直接结合
    • KYN和3-HAA均无此作用

  4. 热稳定性实验：

    • 3-HK以剂量依赖的方式稳定NCOA4，使其免受热变性
    • 直接物理相互作用的证据

  5. 细胞内共定位：

    • 生物素标记3-HK与NCOA4在肿瘤细胞中共定位

  6. 直接相互作用验证：

    • 链霉亲和素下拉和Duolink PLA：证实3-HK和NCOA4之间的相互作用

  7. 结合亲和力测定（SPR和BLI）：

    • SPR：
      • NCOA4³⁸³⁻⁵²² 与 3-HK：KD ≈ 0.8 μM
      • NCOA4-fl 与 3-HK：KD ≈ 0.5 μM
    • KYN和3-HAA均未检测到与NCOA4的结合

【核心发现】

3-HK以高亲和力（KD ~0.5-0.8 μM）直接结合NCOA4的铁蛋白结合域（383-522位氨基酸），破坏NCOA4与FTH1的相互作用，从而抑制铁蛋白自噬的启动。这是首次发现3-HK作为铁蛋白自噬的内源性调节因子。

Result 6：靶向KYN生物合成可增强PAT相关肿瘤对铁死亡和免疫疗法的敏感性#

【目的】 验证药理学抑制KYN通路能否克服铁死亡抵抗，并增强免疫治疗疗效。

【主要证据】

  1. 药理学模型：

    • IDO1抑制剂（epacadostat）+ TDO2抑制剂（LM10）联合使用
    • 显著降低PAT中KYN水平和肿瘤内3-HK水平
    • FTH1、FTL和NCOA4表达相应下调 → 铁蛋白自噬增强

  2. 铁死亡增敏：

    • 在多种模型中验证（CT26 iWAT、DLD1异种移植、CRC PDX、MC38免疫健全小鼠）
    • IDO1/TDO2抑制显著增强肿瘤对铁死亡诱导剂（GPX4敲低/IKE）的敏感性

  3. 免疫治疗协同：

    • IDO1/TDO2抑制 + 抗PD-1抗体：显著增强肿瘤抑制
    • Lip-1可逆转此增强效应 → 证实铁死亡的参与
    • 在腹膜转移模型中得到进一步验证

  4. 临床相关性：

    • 腹膜转移的胃癌患者对新辅助化疗-免疫疗法反应较差

5.1 亮点#

  2. 机制深度：

    • 从代谢物筛选 → 细胞验证 → 蛋白结合 → 结构域定位 → 体内功能的完整证据链
    • SPR/BLI双技术验证结合亲和力，证据扎实

    • 发现了KMO^高^/KYNU^低^作为预测ICB疗效的潜在生物标志物

5.2 局限性#

  1. 3-HK结合口袋的具体结构尚未解析：

    • SPR/BLI显示3-HK结合NCOA4 383-522结构域
    • 但未获得NCOA4-3-HK复合物的晶体结构
    • 3-HK具体结合位点和结合模式仍不清楚

  2. IDO1/TDO2抑制剂的临床转化挑战：

    • 高浓度时RTA活性也参与其中，两者的相对贡献有待精细分离

    • 不同细胞亚群的具体贡献比例尚需精细解析
