中文标题#

基于图关联统一嵌入的单细胞多组学数据整合与调控推断

英文标题#

Multi-omics single-cell data integration and regulatory inference with graph-linked embedding

Nature Biotechnology | IF=41.7 | 中科院1区 | 2022-05-02
Zhi-Jie Cao, Ge Gao
DOI: 10.1038/s41587-022-01284-4

中文摘要#

尽管单细胞中同步测量多种组学模态的实验方法已经出现，但大多数单细胞数据集仍仅包含单一模态。整合多模态组学数据的主要障碍在于，不同组学层通常具有不同的特征空间。本文提出计算框架 GLUE（graph-linked unified embedding，图关联统一嵌入），通过显式建模跨组学层的调控相互作用来弥合这一差距。系统基准测试表明，在异构单细胞多组学数据整合方面，GLUE 比现有最先进方法更准确、更稳健且更具可扩展性。作者将 GLUE 应用于三组学整合、整合式调控推断以及数百万细胞规模的多组学人类细胞图谱构建等多种挑战性任务，并显示其能够纠正既有注释。GLUE 采用模块化设计，可灵活扩展和增强以适应新的分析任务。完整软件包已公开发布于 https://github.com/gao-lab/GLUE。该工作表明，通过建模调控相互作用，可以在图谱级尺度上实现不同单细胞数据模态的整合。

一、研究背景与科学问题#

1.1 研究背景#

单细胞组学技术已经从单一转录组测量，扩展到染色质可及性、DNA 甲基化以及多模态联合测量。现实问题在于：绝大多数公开数据仍是非配对的单模态数据，不同模态之间既没有一一对应的细胞，也缺乏统一的特征空间。比如 scRNA-seq 的特征是基因表达，而 scATAC-seq 的特征是开放染色质区域，直接对齐难度很高。

已有方法通常走两条路线：一是把不同模态强行转换到同一特征空间，再做整合；二是用流形对齐或矩阵分解实现间接匹配。但前者容易损失信息，后者往往难以扩展到三种及以上组学层，或难以处理百万细胞级别的数据。

1.2 科学问题#

  1. 如何在不同组学层特征空间不一致的前提下，稳定整合非配对单细胞多组学数据？
  2. 如何把先验调控知识真正纳入整合过程，而不仅仅作为预处理映射规则？
  3. 如何在完成跨模态整合的同时，进一步做调控关系推断与 atlas 级别扩展？

二、整体研究思路#

本文提出 GLUE（graph-linked unified embedding）框架，核心思想是把“指导图”作为跨组学桥梁，把不同模态的特征连接到同一个图结构中，再联合学习特征嵌入和细胞嵌入。

研究流程可以概括为：

  • 为每一种组学分别建立一个自编码器，保留各自数据分布特性；
  • 构建指导图，把基因、ATAC peak、DNA 甲基化特征等通过先验调控关系连接起来；
  • 通过图自编码器学习特征嵌入，再通过对抗对齐让不同组学中的细胞嵌入进入同一潜在空间；
  • 在统一嵌入空间中做跨模态对齐、标签转移、调控评分估计与 atlas 级分析。

三、逐个 Result 总结#

Result 1：框架设计——用指导图桥接不同组学特征空间#

【目的】 解决不同组学之间特征空间完全不同，无法直接对齐的问题。

【主要证据】

  • 每个组学层使用独立的变分自编码器，适配各自特征空间和数据分布。
  • 指导图节点对应不同组学特征，边表示跨层调控关系，如“ATAC peak—gene”或“甲基化—gene”。
  • 通过对抗判别器，使不同组学的细胞嵌入进入同一潜在空间。

【核心发现】 GLUE 不是先强行做特征转换，而是通过“图 + 嵌入”的方式，在模型内部完成跨模态桥接。

Result 2：系统基准测试显示 GLUE 在整合精度和鲁棒性上领先#

【目的】 评估 GLUE 相比现有方法的整合表现。

【主要证据】

  • 在 SNARE-seq、SHARE-seq、10X Multiome、Nephron、MOp 等数据集上，总体整合得分持续排名第一。
  • FOSCTTM 指标显示，GLUE 在单细胞精细对齐上误差最低。
  • 即使指导图中的相互作用被大比例破坏，GLUE 仍保持较稳定性能。
  • 在细胞数较少时性能会下降，但在中大规模数据集上优势明显。

【核心发现】 GLUE 同时实现了较好的生物学保留、组学混合和单细胞对齐精度。

Result 3：GLUE 成功扩展到三组学整合#

【目的】 验证 GLUE 能否整合超过两个组学层。

【主要证据】

  • 在小鼠皮层数据中整合了 RNA、ATAC 与 DNA 甲基化三层数据。
  • 指导图允许正负符号边，从而表达“ATAC 与表达正相关、甲基化与表达负相关”等关系。
  • 统一嵌入支持标签转移，修正并细化了神经元亚群注释。
  • 联合建模还量化了不同表观遗传层对表达预测的非冗余贡献。

【核心发现】 GLUE 不仅适合双组学，也适合三组学甚至更多层的整合任务。

Result 4：GLUE 的统一嵌入支持整合式调控推断#

【目的】 验证统一嵌入能否进一步用于 peak-gene 调控关系识别。

【主要证据】

  • 在 PBMC 多组学数据中，将特征嵌入余弦相似度定义为调控评分。
  • 调控评分与基因组距离呈负相关、与经验峰—基因相关性呈正相关。
  • 在 pcHi-C 和 eQTL 外部证据验证下，GLUE 比 Cicero、LASSO 和简单相关性表现更好。
  • 进一步推导出的 TF—靶基因网络与 TRRUST v2 数据库一致性更高。

【核心发现】 GLUE 从“整合算法”进一步升级为“整合 + 调控推断”框架。

Result 5：GLUE 支持百万细胞级 atlas 整合#

【目的】 检验 GLUE 在大规模细胞图谱中的可扩展性。

【主要证据】

  • 成功整合了人类胎儿基因表达图谱与染色质可及性图谱。
  • 借助小批量优化、分阶段训练和元细胞预训练策略，实现 atlas 级扩展。
  • 整合后可修正部分原始注释偏差，识别更合理的细胞谱系关系。
  • 对照方法中，online iNMF 质量较差，Seurat v3 在完整规模上难以有效运行。

【核心发现】 GLUE 具备从方法开发走向 atlas 级应用的潜力。

四、机制模型 / 方法模型#

可以把 GLUE 总结为一句话：

先用指导图把不同组学的特征连接起来，再用图嵌入和对抗学习把不同组学的细胞放进同一个潜在空间，最后在这个统一空间中做标签转移和调控推断。

文字流程图：

不同组学数据（scRNA / scATAC / methylation）
        ↓
各自自编码器学习组学层内部表示
        ↓
指导图编码跨组学调控关系
        ↓
图自编码器学习特征嵌入
        ↓
对抗对齐学习统一细胞嵌入
        ↓
跨模态整合 / 标签转移 / 调控推断 / atlas 构建

五、汇报亮点与局限性#

5.1 研究亮点#

  • 方法创新明确：把先验调控图纳入主体模型，而不是只用于预处理。
  • 验证链完整：从双组学、三组学到调控推断和 atlas 级整合，层层递进。
  • 兼顾算法与生物学：不仅看 benchmark 指标，也有真实生物学场景和外部证据支持。
  • 实用性强：scglue 工具开源，易于后续复现与方法对比。

5.2 研究局限性#

  • 在极小样本数据中，神经网络方法可能欠训练。
  • 尽管对错误先验有鲁棒性，但指导图质量仍会影响最终上限。
  • 当前调控推断更偏全局平均效应，时空特异性调控仍需进一步细化。
  • atlas 级训练仍需要较高计算资源和工程实现能力。
