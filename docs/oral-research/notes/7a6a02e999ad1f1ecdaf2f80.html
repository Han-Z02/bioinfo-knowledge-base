方法目的#

差异表达分析用于识别两个或多个条件之间表达水平显著不同的基因，例如疾病组 vs 健康对照组。

适合回答的问题#

  • 牙周炎组织中哪些基因相对健康牙龈显著上调或下调？
  • OSCC 肿瘤组织中哪些基因相对邻近正常组织异常表达？
  • 某个细胞亚群在不同状态下是否存在炎症或代谢相关转录变化？

不适合回答的问题#

  • 单独证明因果关系。
  • 在没有外部验证的情况下直接确定 biomarker。
  • 忽略批次效应后比较不同平台数据。

输入数据#

  • bulk RNA-seq count matrix
  • microarray expression matrix
  • single-cell pseudo-bulk matrix
  • 分组信息和协变量信息

核心步骤#

  1. 数据质控与样本过滤。
  2. 表达矩阵标准化或建模。
  3. 构建设计矩阵。
  4. 进行统计检验。
  5. 多重检验校正。
  6. 可视化：volcano plot、heatmap、PCA。
  7. 下游富集分析：GO、KEGG、GSEA。

常用工具#

R#

  • DESeq2：RNA-seq count 数据常用。
  • edgeR：RNA-seq count 数据，适合复杂设计。
  • limma：microarray 常用；limma-voom 可用于 RNA-seq。

Python#

  • scanpy：单细胞差异表达。
  • pydeseq2：Python 版 DESeq2 风格分析。

关键注意事项#

  • RNA-seq count 数据不要直接对 TPM/FPKM 做 DESeq2。
  • 多数据集合并前要考虑 batch effect。
  • 小样本数据中 p 值不稳定，应重视效应量和跨队列复现。
  • bulk 组织差异表达可能反映细胞比例变化，而不一定是同一细胞内的表达改变。

口腔生信应用场景#

  • 牙周炎 vs 健康牙龈。
  • OSCC tumor vs normal。
  • 牙髓炎、根尖周炎等炎症组织比较。
  • 单细胞中 disease vs control 的 pseudo-bulk 分析。
