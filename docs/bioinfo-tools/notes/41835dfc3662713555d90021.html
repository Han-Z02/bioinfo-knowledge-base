摘要LLM 归库摘要

  • 核心内容： 张泽民团队两篇论文的全场景单细胞配色拆解合集：①Pan-cancer B cell subtypes（多色/四色/三色/双色离散色板）；②Liver tumour immune microenvironment（多色/三色/两色 + Diverging/Sequential 连续变量渐变色阶）。
  • 适用场景： 单细胞 UMAP/t-SNE 亚群配色、组织来源/临床分组柱状图箱线图、Log2FC/表达量热图、细胞通讯气泡图与 FeaturePlot 密度图。
  • 输入： R 环境 + ggplot2；pal_npg() 需 ggpubr 包，brewer.pal() 需 RColorBrewer 包。
  • 输出： 可直接用于 scale_color_manual / scale_fill_manual 的离散色板向量，以及 colorRampPalette 生成的连续色阶。
  • 关键参数： 01 多色 19+9+9 色、四色 16 色、三色 15 色、双色 10 色；02 多色 6 组（5-12 色）、三色 3 组、两色 3 组；连续变量 Diverging（RdYlBu/Spectral/RdBu/navy-white-firebrick）与 Sequential（Reds/Greens/YlOrRd）。
  • 常见错误： 01 的 03/04 组与原代码同名 Subset_color_panel 会互相覆盖，建议改名；pal_npg 依赖 ggpubr；brewer.pal 依赖 RColorBrewer。
  • 与口腔生信连接： 牙周炎/OSCC 单细胞 UMAP 亚群、组间比例图、Marker 热图可直接套用这两套色板，形成与 CNS 文章一致的发表级配色。
  • 下一步处理： 暂未试用；建议下一个单细胞项目作图时套用，对比默认配色效果后沉淀"使用记录"。
  • 归库说明： 分类到 03 生信教程与工具库（可视化与配色工具页），置信度 0.9，理由：公众号配色教程合集、含可复用 R 代码，非单篇论文剪藏。

连续变量渐变色阶（来自 02，补 01 缺失项）

适用于 Log2FC 差异热图、基因表达量热图、UMAP 连续特征、细胞比例/评分。colorRampPalette 来自 R 自带 grDevices；brewer.pal 需 RColorBrewer 包。

# ===== Diverging（双向，0 居中性变量）=====
# 适合 Z-score、LogFC：高值一色 / 低值另一色，中间白或浅色
my_colors <- colorRampPalette(rev(brewer.pal(11, "RdYlBu")))(50)
my_colors <- colorRampPalette(rev(brewer.pal(11, "Spectral")))(50)
my_colors <- colorRampPalette(rev(brewer.pal(11, "RdBu")))(50)
color     <- colorRampPalette(c("navy", "white", "firebrick3"))(50)

# ===== Sequential（单向，从低到高）=====
# 适合表达量、百分比：单一色系由浅到深
my_colors <- colorRampPalette(rev(brewer.pal(11, "Reds")))(50)
my_colors <- colorRampPalette(rev(brewer.pal(11, "Greens")))(50)
my_colors <- colorRampPalette(rev(brewer.pal(11, "YlOrRd")))(50)

选色建议：

  • Z-score / LogFC（有正有负） → 用 Diverging（RdBu / Spectral / navy-white-firebrick）。
  • 表达量 / 百分比（≥0） → 用 Sequential（Reds / Greens / YlOrRd）。
  • 配合 ggplot：scale_fill_gradientn(colors = my_colors) 或 scale_fill_gradient2(low, mid, high)。

使用建议

  1. 离散配色：传给 ggplot 的 scale_color_manual(values=...) / scale_fill_manual(values=...)，或 Seurat DimPlot(cols=...)。
  2. 连续配色：scale_fill_gradientn(colors=my_colors)，或 scale_fill_gradient2(low, mid, high)。
  3. 避免覆盖：
    • 01 篇的 03/04 组与原代码同名（Subset_color_panel），复用时建议重命名（如 panel_tricolor、panel_duocolor）；
    • 02 篇 my_palett4 原文少一个 e，建议改名 my_palette4。
  4. 包依赖：pal_npg() 来自 ggpubr；brewer.pal() 来自 RColorBrewer；colorRampPalette() 为 R 自带。未安装时先 install.packages(c("ggpubr", "RColorBrewer"))。
