摘要LLM 归库摘要

  • 核心内容： Cellpose 是 MouseLand 维护的通用细胞分割项目，当前主线是 Cellpose-SAM / Cellpose4，强调对不同成像条件、通道顺序、目标尺度和 3D 数据的泛化能力。
  • 适用场景： 荧光/明场显微图像中的细胞、细胞核或类器官区域分割；批量图像处理；需要人工修正后继续训练模型的 human-in-the-loop 标注流程。
  • 输入： 2D/3D 图像（如 tif/png/jpg/gif）、可选多通道与 Z-stack、用户标注数据、模型类型（如 cyto / nuclei / cpsam_v2 / cpdino）、细胞直径与通道设置。
  • 输出： 分割 masks、GUI 可视化结果、批处理分割结果，以及 Cellpose3/4 流程中常见的 _seg.npy 等结果文件。
  • 关键参数/步骤： python -m cellpose 启动 GUI；python -m pip install cellpose[gui] 安装图形界面；3D 数据用 python -m cellpose --Zstack；GPU 环境需单独确认 torch/CUDA；新 DINOv3 模型需额外安装 dinov3。
  • 常见错误： torch 装成 CPU 版导致 GPU 不可用；模型权重下载失败；大图/3D 内存不足；通道和直径设置不合理导致过分割或漏分割；许可证信息在 README 徽章、LICENSE 文件与模型/数据声明之间需分别核对。
  • 与口腔生信连接： 可作为口腔组织切片、免疫荧光、细胞培养、类器官或空间组学配套显微图像的上游分割工具，为后续单细胞/空间分析、细胞计数、形态定量和区域提取提供基础掩膜。

Cellpose（MouseLand）细胞分割项目

项目定位#

  • 仓库地址：MouseLand/cellpose
  • 官方描述：a generalist algorithm for cellular segmentation with human-in-the-loop capabilities
  • 主要语言：Python
  • GitHub 状态：2026-06-08 查看时约 2231 stars / 626 forks；默认分支为 main，当天仍有 push 记录，说明项目仍在活跃维护。
  • 主页入口：https://huggingface.co/spaces/mouseland/cellpose
  • 最近 release：v4.1.1（2026-03-31）；README 还写了 v4.2+ update (June 2026)，说明主线功能仍在继续迭代。

我目前抓到的核心能力#

  1. 通用细胞/细胞核分割：核心目标是显微图像中的细胞级实例分割，而不是只适配单一组织或单一成像模式。
  2. Cellpose-SAM / Cellpose4：README 明确强调最新主线是 Cellpose-SAM，并在 2026 年 6 月加入了基于 DINOv3 的新模型（cpdino、cpdino-vitb）。
  3. human-in-the-loop 训练：不仅能直接跑预训练模型，还支持人工修正后继续训练自己的模型，适合实验室逐步积累特定样本数据。
  4. 3D 分割：支持 Z-stack / 3D tiff，说明不只适合常规 2D 显微图。
  5. 图像恢复能力：Cellpose3 起加入 image restoration，可先做图像恢复再改进分割表现。
  6. 多入口使用：既能在 GUI 手工交互，也能通过 CLI、notebook、Hugging Face Space 和 GitHub 开发版使用。

安装与运行抓手#

1. 常见安装方式#

  • Conda：推荐 conda create --name cellpose python=3.12 后再 python -m pip install cellpose[gui]
  • 纯 Python / venv：适合不想装 conda 的情况
  • GitHub 开发版：pip install git+https://www.github.com/mouseland/cellpose.git
  • 新 DINOv3 模型：需要额外安装 python -m pip install git+https://github.com/facebookresearch/dinov3

2. 常见启动方式#

python -m pip install cellpose[gui]
python -m cellpose

python -m cellpose --Zstack
  • Windows 可直接用打包的 cellpose.exe
  • 如果要做批处理，可通过 CLI 指定目录、通道、保存格式
  • 预训练模型首次运行时会自动下载权重

3. 官方给出的关键前提#

  • 支持 Linux / Windows / Mac
  • 至少 8GB RAM；大图和 3D 体数据可能需要 16–32GB
  • 如果走 GPU，必须额外确认 torch 与 CUDA 驱动是否匹配
  • README 明确提示：若 GPU 不工作，常见原因是误装了 CPU 版 torch

对生信 / 显微分析的实际价值#

1. 口腔组织与细胞成像上游分割#

如果你后面要处理：

  • 口腔鳞癌组织切片中的细胞核轮廓
  • 免疫荧光图中的细胞/核分割
  • 类器官或培养细胞图像中的细胞计数与形态测量
  • 空间转录组配套显微图像中的区域提取

那么 Cellpose 可以作为一个比较通用的上游工具。

2. 对后续分析的连接点#

Cellpose 产出的 masks 可以继续用于：

  • 单细胞或空间层面的 ROI 提取
  • 细胞密度、面积、圆度、邻域结构等形态学统计
  • 下游 CellProfiler / napari / 自定义 Python 脚本的定量分析
  • 训练自己的口腔样本专用分割模型

3. 为什么值得单独入库#

它不是一篇一次性教程，而是一个持续维护的“工具基础设施”型项目：

  • 有论文线（Cellpose 1/2/3 与 Cellpose-SAM）
  • 有代码线（GitHub 仓库）
  • 有文档线（ReadTheDocs）
  • 有在线体验入口（Hugging Face Space）
  • 有 notebook 示例，适合以后直接复现

使用时特别要注意的点#

  1. 模型/代码/数据许可要分开看
    GitHub API 与 LICENSE 文件正文显示代码许可证是 BSD-3-Clause；但 README 徽章仍显示 GPL v3；同时 README 又说明模型训练数据和标注数据为 CC-BY-NC。如果未来涉及再分发或商业使用，最好分别核对代码、模型权重和训练数据的许可范围。

  2. GPU 环境不一定开箱即用
    README 虽然给了安装路线，但真正跑通通常还要看本机 torch 版本、CUDA 版本、驱动与显卡是否匹配。

  3. 大图 / 3D 数据要提前考虑内存
    项目明确写了大图和 3D 体数据可能需要 16–32GB RAM，因此不适合毫无准备地直接全量批处理。

  4. 口腔样本最好记录自己的经验参数
    比如不同染色、不同放大倍数下的直径估计、通道选择、是否先做 restoration、是否适合 nuclei 还是 cyto 模型，这些都值得单独记成试用笔记。
