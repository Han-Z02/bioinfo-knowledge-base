单细胞实战之 Ro/e、Augur、miloR——入门到进阶（中级篇4）

开篇#

在上一讲中完成了 inferCNV 分析流程。本讲回顾单细胞分析中的三个工具：Ro/e、Augur、miloR，分别用于判断细胞簇在组织中的分布倾向、细胞簇受扰动的影响程度以及细胞差异丰度。

原文说明工程文件可通过网盘获得，并提示可向“生信技能树”公众号发送关键词“单细胞”获取 Seurat V5 版本完整代码。网盘示例数据没有复制到本地知识库或远程代码库。

Ro/e——判断细胞簇在组织分布中的倾向#

Ro/e 也称 STARTRAC-distribution，是 STARTRAC 框架中的一个工具。它通过计算组织中的观测细胞数与期望细胞数的比率，判断某个细胞簇在特定组织中是富集还是耗竭。Ro/e 大于 1 表示观测细胞数高于期望值，Ro/e 小于 1 表示低于期望值。

原文给出的评分规则为：+++ 表示 Ro/e > 1；++ 表示 0.8 < Ro/e <= 1；+ 表示 0.2 <= Ro/e <= 0.8；+/- 表示 0 < Ro/e < 0.2；- 表示 Ro/e = 0。原文同时提醒，期望细胞数仍然基于现有数据估计，最后得到的是比率，细胞数过少时容易出现较大偏倚。

原文 Ro/e 流程包括：读取 Seurat 对象；从 metadata 提取 clone.id、patient、majorCluster 和 loc；使用 calTissueDist() 并选择 method = "chisq"；最后用 ComplexHeatmap 画 Ro/e 矩阵热图。示例比较左右半结肠，展示不同 T 细胞簇在组织位置中的相对富集。

Augur——判断扰动影响#

Augur 使用机器学习框架量化扰动和未扰动细胞在高维空间中的可分性。它针对每一种细胞类型训练分类器，通过交叉验证评估分类准确性，并使用 AUC 对细胞类型排序。高 AUC 表示该细胞类型的表达更能区分实验条件。

原文以左右半结肠位置作为实验分组，使用 calculate_auc() 计算 AUC，并用 plot_lollipop() 与 plot_umap() 展示结果。原文示例中 Naive T 的 AUC 较高，说明其表达状态更能区分两类位置；这并不等同于该群体数量更多，也不能单独证明因果关系。

miloR——判断细胞差异丰度#

miloR 在单细胞的 KNN 图上定义重叠邻域，再按照样本统计每个邻域中的细胞数，比较不同条件下的邻域丰度。原文流程包括：Seurat 转为 SingleCellExperiment；构建 Milo 对象；使用 buildGraph() 和 makeNhoods() 构建邻域；使用 countCells() 按样本计数；建立实验设计；使用 calcNhoodDistance()、testNhoods() 和 Spatial FDR 完成差异丰度检验；最后用 annotateNhoods()、plotNhoodGraphDA()、plotDAbeeswarm() 和 marker 分析解释显著邻域。

原文特别强调邻域参数需要和 PCA、KNN 设置一致，prop 可从 0.1-0.2 开始，并通过邻域大小直方图检查结果。原文示例把 location 作为实验条件，比较左右半结肠，并进一步进行 DA 邻域分组、marker 和邻域内差异表达分析。

注意原文参数边界 原文演示中使用了较宽松的 SpatialFDR < 0.9 和 alpha = 0.9。正式分析应根据研究设计预先定义显著性阈值，并以真实生物学重复为统计单位。整理后的远程脚本默认使用 fdr_cutoff = 0.10，需结合数据调参。

原文结论#

三个工具各有侧重点，也可以用于同一批数据的不同分析视角：Ro/e 描述组织分布，Augur 筛选扰动敏感的细胞类型，miloR 在连续细胞状态或邻域层面检测差异丰度。结合使用可以得到更全面的单细胞生物学解释。
