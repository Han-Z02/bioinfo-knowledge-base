你是否上手Jupyter-Noteboook分析数据的时候感觉到有点困难？尤其是对于单细胞而言，为了便利小白和我自己，于是我开发了这一款极其轻便的插件，仅100Kb，只有两个依赖。

Steorra

1. 安装#

安装非常非常简单，没有OmicVerse的重依赖，仅需使用pip，完全兼容scanpy的生态体系，即使你没有安装omicverse。

pip install omicverse-notebook

2. 设置#

我们仅需要在我们的Jupyterlab的代码行前加上一句 %load_ext omicverse_notebook 即可，只需要加一次，后续所有代码均生效。

%load_ext omicverse_notebook
import pandas as pd

3. 报错显示优化#

你还在为报错显示而苦恼吗？借助OmicVerse-Notebook，我们可以非常清晰地看见报错信息的全方位定义

3.1 核心报错信息#

我们将最核心的报错信息放在顶部

3.2 报错内容#

当你点击 What 按钮，你将看见报错信息的解释（非Agent）

3.3 报错原因#

当你点击 Why 按钮的时候，你将看见报错信息的原因

3.4 报错位置#

当你点击 Where 按钮的时候，你可以看见报错信息发生的具体位置。

3.5 原始报错信息#

当然原始的报错信息你也可以点击 Traceback 查看，然后复制到大语言模型里Debug。

4. AnnData显示优化#

4.1 AnnData基础显示优化#

我们全面优化了AnnData的显示效果，将每个变量都做成了可点击的按钮，这样可以非常方便地查看AnnData的具体内容，不需要写额外的代码。

4.2 AnnData可视化优化#

我们还支持直接查看umap/spatial等一切存放在obsm里的内容

5. DataFrame显示优化#

我们在优化AnnData的过程，顺带把Pandas库里的DataFrame的显示也进行了优化

6. 双色主题#

安装完OmicVerse-Notebook后，你还将同时获得双色的Jupyterlab主题

6.1 浅色系#

点击 Setting -> Theme -> omicverse-light 即可替换

6.1 暗色系#

点击 Setting -> Theme -> omicverse-dark 即可替换

7.结语#

本插件的作用仅是优化大家的分析体验，毕竟，我们打算做最好的开源组学分析生态。
