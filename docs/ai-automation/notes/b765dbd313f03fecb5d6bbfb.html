项目：HKUDS/CLI-Anything（43.5k Stars, Apache 2.0） 📄 arXiv: 2606.03854 🌐 CLI-Hub: https://clianything.cc/

核心理念#

今天的软件为人而生，明天的用户是 Agent。CLI-Anything 通过自动生成结构化 CLI，让任意软件（GIMP、Blender、LibreOffice 等）直接能被 AI Agent 调用——无需 GUI 自动化、无需专用 API、无需重构代码。

为什么是 CLI？#

  • 结构化可组合 - 文本命令天然匹配 LLM 格式
  • 轻量通用 - 零开销，跨平台
  • 自描述 - --help 即可让 Agent 发现所有功能
  • Agent 原生 - JSON 输出消除解析复杂度
  • 确定可靠 - 输出一致，行为可预测

CLI-Hub 包管理器#

pip install cli-anything-hub 后可使用：

命令 功能
cli-hub list 浏览注册表
cli-hub search <query> 搜索
cli-hub info <name> 查看详情
cli-hub install <name> 安装 CLI
cli-hub launch <name> 运行 CLI

开源社区已贡献 30+ 软件 CLI（GIMP、Blender、OBS、Zotero、Joplin、FreeCAD 等）。

支持的 AI 平台#

  • Claude Code - /plugin marketplace add HKUDS/CLI-Anything + /plugin install cli-anything
  • OpenCode - 复制 opencode-commands/ 到命令目录
  • Codex - bash codex-skill/scripts/install.sh
  • OpenClaw - 安装 SKILL.md
  • GitHub Copilot CLI - copilot plugin install ./cli-anything-plugin
  • Qodercli - 社区贡献插件

自动生成流程（7 阶段）#

  1. 🔍 分析 - 扫描源码，GUI 操作映射到 API
  2. 📐 设计 - 命令分组、状态模型、输出格式
  3. 🔨 实现 - Click CLI + REPL + JSON 输出 + 撤销/重做
  4. 📋 规划测试 - 生成 TEST.md
  5. 🧪 编写测试 - 完整测试套件
  6. 📝 文档 - 更新 TEST.md
  7. 📦 发布 - setup.py，安装到 PATH

核心命令#

命令 功能
/cli-anything <路径> 完整构建
/cli-anything:refine <路径> [方向] 优化扩展
/cli-anything:test <路径> 运行测试
/cli-anything:validate <路径> 标准验证
/cli-anything:list 列出已安装 CLI

架构特点#

  1. 真实软件集成 - 直接调用 GEGL、bpy、sox、melt 等真实后端
  2. 双模式交互 - REPL（有状态）+ 子命令（脚本/流水线）
  3. 统一体验 - 共享 repl_skin.py 界面
  4. JSON 输出 - Agent 原生设计
  5. 可嵌入 Skill - 每个 CLI 附带 SKILL.md

已知局限#

  • 依赖前沿模型（Claude Opus/Sonnet、GPT-5.4）才能可靠生成
  • 需要可用的源代码（编译后二进制效果差）
  • 通常需要多次 /refine 迭代才能达到生产级

与已有工具的关系#

工具 定位差异
MCP 通过 JSON-RPC 提供服务端能力；CLI-Anything 通过 CLI 接口，更轻量、更通用
Claude Code 插件 CLI-Anything 本身可作为 Claude Code 插件市场安装
Skills 每个生成的 CLI 都自动生成 SKILL.md，可被 OpenClaw/Codex 等使用
