今天，和大家分享下如何简单的让 Claude Code 接入任意的大模型，不管是Gemini、GPT、Qwen、三方中转等API都支持。

一、先搞明白，Claude Code是个啥？
Claude Code 是由 Anthropic 开发的一款智能编程工具（也称为编程助手或AI代理）。 它直接在开发者的终端环境中运行，能够理解整个代码库，并通过自然语言指令帮助开发者更高效地编写、理解和修改代码。
对于开发工作相关的同学来说，它能干嘛？

  • 项目冷启动？ 搭框架。（“用Next.js + TypeScript给我搭个项目框架，带上 ESLint 和 Prettier 配置。”）
  • 祖传代码看不懂？ 扔给它，帮你梳理逻辑，加注释。（“@legacy_api.py 这个文件是干嘛的？给我解释一下核心逻辑，并加上中文注释。”）
  • 屎山想重构？ 它就是你的铲屎官。（“重构这个Java类，把回调地狱改成响应式编程风格，用 Project Reactor 实现。”）
  • 排查BUG？ 把错误日志甩给它，秒定位问题，然后直接帮你修复。
  • 想学门新语言？ 让它把你的Python项目翻译成Go，边看边学，事半功倍。

对于想要给工作提效的同学来说，它又能干嘛？

  • 自动化日常任务： 用一句话让它批量整理文件、重命名照片，或从文档中提取信息（如邮箱、电话）并存入表格，告别手动复制粘贴。
  • 成为你的数据分析师： 无需复杂的软件，直接向它提问，就能快速分析表格数据，找出关键信息，比如哪个产品卖得最好？。
  • 做你的编程与学习导师： 想学做网页或写个小脚本？它能手把手教你，为你生成代码、解释原理。
  • 帮你实现创意想法： 你可以通过与它对话，一步步将自己的小工具或个人网站的想法变为现实。

总之一句话： 你负责想，Claude Code负责实现。

二、简单搞定安装：
废话不多说，直接上干货。想用上这么好用的工具，马上开始实操
第一步：安装 NodeJS
Claude Code 需要NodeJs才可以运行
首先访问： nodejs.org ，下载最新LTS版本的NodeJs

根据你使用的系统，选择对应的版本，下载好之后一直下一步安装即可
第二步：安装Claude Code和Claude Code Router
Claude Code 是我们今天的主角， Claude Code Router 则是一个非常优秀的开源项目，可以让我们简单的几步操作就可以将任意的大模型接入 Claude Code 。
打开你的终端（命令行工具），执行以下的命令

第三步：配置接入大模型
打开终端，输入 ccr ui 如果你已经成功安装好了 Claude Code和Claude Code Router， 这个时候应该会自动在浏览器弹出一个可视化配置的页面
点击添加供应商

第四步：万事俱备，启动！
在你想要使用Claude Code的文件目录打开终端，输入： ccr code 就可以启动 Claude Code
启动之后就可以指挥 Claude Code 干活啦

有一些同学可能会不习惯使用命令行的方式编程，觉得使用VS Code会方便些，这也非常简单，只需要在VS Code的终端中输入 ccr code 它会自动帮你安装配套的VS Code扩展
这有啥好处？

  • 代码看得见摸得着： 你在编辑器里选中一段代码，Claude那边立刻就能知道你在说啥。
  • 一键修改，告别复制粘贴： 它提的代码修改建议，会直接以Diff（差异对比）的形式出现在你面前，你只需要点一下“接受”，代码就自动改好了，方便优雅！

三、如何让Claude指哪打哪？
工具是好工具，但很多人用不好，问题出在“不会提问”。
不要废话文学、表达不清楚的提问：

  • “写个排序。”（写啥排序？啥语言？升序降序？）
  • “我代码崩了，救命！”（哪段代码？报了什么错？）
  • “优化一下。”（从哪方面优化？性能？可读性？还是代码结构？）

要高效指令式提问：

  • 任务清晰： “用Python写一个 快速排序 函数，函数名叫 quick_sort ，它应该接受一个 整数列表 ，返回一个 新的排好序的列表 ，并为关键步骤 添加注释 。”
  • 上下文拉满： “我正在运行这段JavaScript代码（ @app.js ），浏览器控制台报了这个错： TypeError: Cannot read properties of undefined ，错误发生在第25行。 我怀疑是API返回的数据结构变了 。你帮我分析下原因，并给出修复建议。”
  • 目标明确： “请重构 fetchData 这个函数（ @api/service.js ）。目标是 提高可读性和错误处理能力 ，请将 .then() 链式调用改为 async/await 语法，并添加一个 try...catch 块来捕获API请求失败的异常。”

看到没？ 上下文、意图、细节 ，这三样给足了，AI给你的反馈质量才会指数级上升。

四、进阶篇：选对模型
掌握了基础对话，你已经能超过80%的用户了。
1. 模型怎么选？
简单说，这就是 Claude Code 的大脑，模型选的好效果好，模型要选对而不是选贵，合适的才是最好的，不然钱包遭不住。
我来分享些我的小经验：

  • Gemini 2.5 Pro：一 百万超长下文，编程能力相对不错、文本生成能力出色，写出的文章是情商拉满，适合日常对话聊天、编程、工作提效；性价比均衡，不知道怎么选就选2.5Pro一般不会错
  • Cladue Opus 4.1 ： 编程能力很强大，是其一大特色；价格比较贵，适合经常编程且经济实力不错的同学选择
  • GPT-5 ： 相比上一代，医疗知识水平提高很大，适合平时聊天和做一些咨询，写文能力相对较弱
  • 国内模型（如 通义千问 、 DeepSeek 等）: 国内的大模型也在快速进步，例如阿里的通义千问（Qwen）和深度求索（DeepSeek）都在各大编程能力评测榜单上取得了不错的成绩。 它们对中文编程场景和文档的理解可能更具优势，并且价格实惠，大家根据需求灵活使用

2. 给你的AI上个“项目Buff”： CLAUDE.md
想让 Claude Code 更懂你的项目？使用 /init 指令， Cladue Code 会自动分析项目的情况然后在项目根目录创建一个叫 CLAUDE.md 的文件。
这个文件就是给AI准备的项目说明书。每次启动， Claude Code 都会先读一遍。有了它， Claude Code 运行时只需要读取一次这个文件，就对项目了如指掌。
写在最后：拥抱新范式，而非新工具
归根结底，我们必须跳出一个狭隘的认知：AI不是一个被动响应的工具箱，而是一个主动赋能的新范式。
拥抱 Claude Code 这样的新一代AI伙伴，正是拥抱这种新范式的开始。 对开发者而言 ，这意味着将繁琐重复的“编码体力活”彻底外包给AI，从而将100%的精力聚焦于架构设计、复杂逻辑和产品创新——这些真正铸就顶尖工程师价值的核心领域。
而这种变革，并不局限于开发者。 无论你从事任何岗位，都可以利用它的能力为自己赋能。比如，让它为你编写一个自动化脚本，将每周数小时的报表整理工作压缩到一键完成。
最终，无论是编写代码还是处理日常事务，目标都是一致的： 将我们从重复、繁琐、无趣的“执行”中解放出来，去思考真正重要的问题，去规划下一步的走向。
这不仅是一次效率的飞跃，更是一次价值的重估。它迫使我们去回答一个根本性的问题： 当执行的成本变得极低时，我们作为人类的独特价值究竟是什么？
你的答案，将决定你在这个时代的最终位置。
