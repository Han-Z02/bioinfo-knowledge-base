摘要LLM 归库摘要

  • 核心内容： 这篇剪藏记录了作者为“生成可编辑科研示意图”测试 GPT-Image、Claude Code、Codex 桌面版、ChatGPT 网页版输出 SVG 等方案的过程。
  • 主要结论： 直接让 AI 从 PNG 反推或生成精确 SVG 往往成本高、token 消耗大且失真明显；相对可行的是 ChatGPT 网页版生成 PNG 后再输出 SVG，并用 Adobe Illustrator 等矢量编辑器继续人工修。
  • 可复用知识： AI 适合作为科研绘图辅助，但最终可编辑性、准确性和发表级美观仍依赖 SVG/AI 等矢量流程与人工校正。
  • 工具边界： Claude Code / Codex 直接写复杂 SVG 容易超过输出上限或误解图像结构；AI 生图存在随机性和潜在“AI 数字签名/水印”问题。
  • 关联页面建议： 可后续整合到 04 AI_API与自动化库/02_wiki/claude_code/科研绘图与可编辑 SVG 工作流 或 04 AI_API与自动化库/02_wiki/skills/AI 科研绘图工具评测。
  • 下一步处理： 若要沉淀为稳定 workflow，建议实测 ChatGPT→SVG→Illustrator/Inkscape、Open Design、Vectorizer 等路径，并记录输入提示词、输出格式、编辑成本与失败案例。
  • 归库说明： 分类到 04 AI_API与自动化库，置信度 0.88；理由是正文高度集中于 GPT-Image、Claude Code、Codex、SVG 输出和 AI 科研绘图自动化经验。

今天受师兄委托，看看有没有法子可以让AI进行科研绘图，要求可编辑的格式

我纳闷了，GPT-image2.0和nano banana都只能做成png静态图片，虽然官网有圈选指定位置修改的功能

但是这功能特别鸡肋啊，反反复复修改甚至没有第一版的要好

后来我问了Claude ，他跟我说：

最好的办法就是使用svg代码绘制图像，然后到svg编辑器（比如开源的inkspace和破解版的Adobe illustrator）

只有这样子出来的图片后期才可以手动编辑
